# Econophysics Probabilistic State Modeling

This example demonstrates econophysics concepts by simulating a multi-asset portfolio under probabilistically changing market states. It uses a Markov chain to model market regimes (Bullish, Bearish, Sideways) which influence asset price movements, and applies portfolio-level control actions based on the detected state. This illustrates how probabilistic state modeling can inform dynamic portfolio management strategies.

## Language

`python`

## How to Run

Save the code as `main.py`.
Run from your terminal: `python main.py`
